# Zarbot

Facebook группүүдэд зараа автоматаар тавьдаг Windows програм.

**Суулгагч татах:** [Releases → хамгийн сүүлийн хувилбар](https://github.com/Yesudei/zarbot-updates/releases/latest) → `ZarbotSetup-….exe`

- Ашиглахад худалдаж авсан **лицензийн түлхүүр** хэрэгтэй.
- Windows 10/11 (64-bit) болон Google Chrome шаардлагатай.
- Суулгасан Zarbot шинэ хувилбар гарахад өөрөө мэдэгдэж, нэг товчоор шинэчлэгдэнэ.

⚠️ Facebook автомат програм ашиглахыг дүрмээрээ зөвшөөрдөггүй тул хаяг хязгаарлагдах, хаагдах эрсдэлтэй. Програм анх асахдаа энэ анхааруулгыг уншуулж, зөвшөөрөл авна.

---
Энэ репод зөвхөн суулгагч болон гарын үсэгтэй шинэчлэлтийн файлууд (`app.json`, `selectors.json`) байна. Програм зөвхөн зөв гарын үсэгтэй файлыг хүлээн авдаг.
